# Openrooms

Openrooms is an open-source first-person exploration game built with Godot.

The project is inspired by liminal spaces and maze-like artificial environments.

The current prototype focuses on:

- first-person exploration;
- large maze-like indoor environments;
- dynamic proximity-based lighting;
- dark areas requiring a flashlight;
- atmospheric exploration without enemies.

Openrooms is currently in early development.

## Engine

Godot 4.x

## Platform

Development currently targets Linux.
